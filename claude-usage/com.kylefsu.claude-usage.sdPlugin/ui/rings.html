Windows, models and ceilings

Window is in hours: 5 for the session window, 168 for a week, 24 for a day.

Model is a case-insensitive substring of the model id, so fable matches claude-fable-5 and opus covers every Opus revision. Leave it empty to count everything.

Ceiling is the effective-token total that means 100%. Claude Code keeps no plan limits on disk, so run npm run report in the plugin folder and compare its windows against /usage. The report also breaks usage down per model, which is what you want for a model-specific key.

Leave a ceiling empty and the ring stays dark while the readout shows raw tokens.
