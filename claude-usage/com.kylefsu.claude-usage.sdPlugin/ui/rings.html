What do I put in “Ceiling”?

It is the number of tokens that should read as 100%. Claude Code keeps no plan limits on disk, so the plugin cannot know yours — you set it once.

Long-press this key to open /usage, then run npm run report in the plugin folder. If /usage says you are at 50% and the matching row in the report reads 20M, your ceiling is about 40M.

Leave it empty and the ring stays dark, while the readout shows raw tokens instead of a percentage. The key still works — it just cannot draw a proportion of nothing.

Only this model is a partial name: fable matches claude-fable-5, opus covers every Opus. The report breaks usage down per model so you can set a ceiling for one.
