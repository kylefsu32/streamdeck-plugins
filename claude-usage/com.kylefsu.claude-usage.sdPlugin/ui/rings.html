Where the numbers come from

Session limit and Weekly limit are Anthropic's own figures — the same source /usage reads — so they are exact, need no ceiling, and the caption counts down to the real reset. Getting them means reading Claude Code's OAuth token from your keychain; it is used only to ask Anthropic for your usage, and is never logged or sent anywhere else. macOS will ask once for keychain access; choose Always Allow or the key will sit at 0%.

The Tokens options are counted from your local transcripts instead. They need a ceiling, but they can do what the API cannot: filter to one model, or use any window you like. Session block models the 5-hour block — it opens on your first message, runs five hours whatever you do inside it, then resets.

To set a token ceiling, run npm run report in the plugin folder and compare against /usage. If /usage says 50% and the matching row reads 20M, the ceiling is about 40M. Left empty, the ring stays dark and the readout shows raw tokens.
